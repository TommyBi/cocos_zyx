## 道具

1、奶滴 - 按照广告数量计发 8~10次广告调用，游戏内产生一枚奶滴
2、金币 - 关卡中不定时产生的游戏代币，每百层释放20~40个代币
3、盒牛奶 - sku1
4、箱牛奶 - sku2
5、奶酪 - sku3
6、一盒酸奶 - sku4
7、炸弹 - 局内道具 - 炸掉3行
8、锤子 - 局内道具 - 敲掉1个
9、体力 - 局内道具 - 用于挑战的入场券，每次挑战消耗1点体力，上限8点，每10分钟恢复1点

## 兑换比例（兑换比例）
1盒牛奶 = 400奶滴（满10盒发货）
1箱牛奶 = 12盒牛奶（满1箱发货）
1包奶酪 = 10盒牛奶（1包发货）
1盒酸奶 = 800奶滴（6盒发货）
炸弹 = 2000金币
锤子 = 300金币
体力 = 500金币

## SKU计费原理
刨除微信分成50%结算，ecpm按照最低10（千次广告10元钱收益）计算得到 0.01元/条广告
1盒奶成本 = 3元 对应333次广告带来的收益，按照20%的投放收益，对应333/0.2 = 1665次广告 即保守估计2000次广告 = 一盒牛奶成本 如果想盈利50%，那么对应4000次广告 = 1盒牛奶，即1盒牛奶 = 400奶滴，每8~10次广告使用量释放一滴牛奶

单用户每日15~20次广告调用量，每日完成80%广告播放，大约200天可获得1盒牛奶

##防作弊策略：
每日奶滴发放上限 3
奶滴数达上限时 当日广告播放次数一定大于20

##裂变激励策略
邀请注册用户奖励1奶滴；
邀请注册用户完成10奶滴积累，奖励10奶滴；

## 游戏主线流程

```
新用户
  → 自动引导局1 → 胜利结算
  → 引导局2 → 胜利结算
  → 引导局3 → 胜利结算
  → 返回主界面
  → 页面功能介绍引导
  → 引导挑战开始
  → 自主挑战
```
```
老用户
  → 主界面 → 开始游戏的小手弱引导 + 任务的提示 + 近一个小时的兑换记录滚动提示
  → 自主挑战
```

## 关卡设计
1、自主挑战后的前二十局由简入难，并适当放出道具作为激励货币；
2、前20局 每5局为一个难度配置，由简变难，直到第4个5局结束后，难度走统一配置；
