# 双页签排行榜 · 美术提案

状态：双页签、领奖台、固定我的排名及余额榜接口已在本地预览落地。字体统一为 Regular 400，CDN 异步字体方案仍待评审；本轮未向线上部署双榜。

## 排名含义

- 积分榜：按历史单局最高分降序。
- 开心榜：按当前拥有的开心豆余额降序；消费后余额和名次可能下降。不是累计获得量。
- 两个页签采用同一布局；各自展示对应榜单的我的排名和数值。
- 样例数据仅供排版，不代表线上玩家数据。

## 美术方向

延续现有奶油面板、焦糖边框、暖棕文字、软糖质感按钮和叶芽开心豆角色。将前三名做成紧凑小领奖台，普通列表收敛背景装饰，底部固定自己的排名。开心榜使用嫩绿色激活态，积分榜使用蜂蜜金激活态。

配色：奶油底 #FFF5DC、焦糖边 #D5A255、可可文字 #684B39、蜂蜜金 #F6C85F、嫩叶绿 #B6D896、薄荷按钮 #79BE91。

字体：圆润简体无衬线，标题、正文与数字全部使用正常字重，不额外加粗；数值保持列对齐。

布局：浮动标题牌 → 双页签 → 口径提示 → 前三名领奖台 → 第 4–6 名列表 → 固定我的排名 → 关闭。领奖台按 2 / 1 / 3 排列，其余列表姓名左对齐、数值右对齐。页签切换时各区域位置一致。

角色以当前截图的黄色叶芽豆为准；禁止使用已废弃的有孔圆柱拼豆。

## 设计自审

主视觉仅集中在前三名领奖台。保留游戏自己的颜色和圆润形态，不使用通用网页卡片风格；其余区域减少装饰，保证昵称与数值在手机上易读。两个页签仅切换主题强调色和榜单内容，不造成布局跳动。

不设计额外奖励、周期、清榜或累计收益机制。
