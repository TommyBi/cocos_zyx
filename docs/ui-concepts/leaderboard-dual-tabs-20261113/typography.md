# 可落地的排行榜字体方案

> 本文保留首版字体提案及截图记录。后续已按用户要求改为全局 Regular 400，并完成本地双榜预览；最新状态见 `docs/leaderboard-dual-tabs-2026-11-13.md`。下文的 800 字重、额外增重和仅排行榜接入均为历史方案，不再代表当前预览。CDN 分层加载仍待评审。

原美术稿中的文字是图像生成的字形，不对应一份可导出的完整字体。此次用真实开源字体制作可重复构建的游戏资源，并接入现有排行榜，先解决字体还原的问题。双页签的业务、领奖台布局和开心榜接口仍未开发。

## 字体与样张

中文基于寒蝉全圆体 ChillRoundF；数字基于 Nunito 800。标题、固定文案、排名和数值使用 96px 的 BMFont 图集，中文统一增重 2px，运行时关闭模拟加粗。动态昵称采用重命名后的 TTF 子集 Zyx Happy Round Body，包含 7504 个映射字符，覆盖常用 GB2312 中文、拉丁和标点；生僻字及表情使用文本渲染器的字体回退。

- `typography-proof.png`：直接读取运行资源的字体排版样张；布局用于字体审阅，不代表双页签已实装。
- `typography-proof.html`：可缩放的字体样张源文件。
- `font-before-cocos.png` / `font-after-cocos.png`：相同示例数据下，现有排行榜的 Cocos 渲染对照。
- `font-responsive-proof.json`：小屏、平板、长昵称、表情、生僻字、8 位数值及未上榜状态检查记录。

## 游戏接入

字体保存在首页 home 分包，仅作用于现有排行榜弹窗。AssetLoader 在首页渲染前准备字体资源，弹窗统一绑定字形资源，昵称独立绑定 TTF。系统字体、其他页面样式和排行数据逻辑不受此次改动影响。

运行资源约 2.68 MiB，主要是中文昵称字体。没有把完整原字体复制进小游戏主包。OFL 许可随字体资源分发，字体子集因保留名称规则已重命名，未宣称为独立原创字库。

源文件与授权说明：`docs/art-sources/fonts/leaderboard-v1/`。重建脚本：`scripts/build-leaderboard-fonts.py`（Pillow + fonttools）。
