# 《烦恼排排消》正式 UI 实施规范 V2

## 1. 视觉定位

- 风格：温暖日漫、软陶般半 3D、全年龄、不过度粉色；左上局部反光、右下厚边和柔和接触阴影构成统一光源，禁止使用生硬的横向白色高光条。
- 主题：首页是“心情画布”，局内是暖光日漫“心情整理屋”，两套环境必须能一眼区分。
- 唯一强记忆点：表情从碎裂色块飞入玻璃瓶，瓶盖像打饱嗝一样弹起，瓶内进度随之增长。
- 首页环境动效：只允许单层低对比度斜向表情墙缓慢往返，不做双层交叉淡入淡出，不做循环缩放。
- 水印表情约 80% 为积极心情；局内禁止使用运动水印墙与幼儿化角色，只使用窗光、植物、木架、书本和玻璃器皿建立空间层次。

## 2. 色彩与材质

| 角色 | 色值/范围 | 用途 |
| --- | --- | --- |
| 奶油纸 | `#FFF6E0` | 棋盘槽位、浅层面板 |
| 蜂蜜黄 | `#F4B53C` | 获取、开始等主要行动按钮 |
| 顺心绿 | `#69B581` | 继续、确认、已选中按钮 |
| 珊瑚红 | `#E2685F` | 暂停、取消、退出按钮 |
| 可可 | `#583D37` | 正文、棋盘框架 |
| 鼠尾草绿 | `#7EB392` | 选中态、安心反馈 |
| 雾蓝 | `#6FA4C1` | 次级信息 |
| 珊瑚红 | `#DC6F62` | 新纪录、需要注意的反馈 |

所有色块使用统一的半立体规则：2.3px 深色描边、左上局部椭圆反光、右下厚边、柔和接触阴影、14px 左右圆角。槽位与色块统一保留 2px 内边距，避免漏边。所有可点击按钮只使用蜂蜜黄、顺心绿、珊瑚红三种动作色，并复用同一材质规则。

棋盘采用独立四层结构：圆角浅色盘面、低透明网格水印、裁剪视口内的交互色块、最上层可可色边框。网格线透明度约 28%，线宽 2.4 设计像素，确保经过微信设备缩放后仍能稳定提供落位基线，但不与色块竞争视觉焦点；阴影与边框共用同一外轮廓，只允许向下偏移形成景深。所有新行、碎片和提示动画都必须受棋盘视口裁剪。棋盘下方另设向内收边的不透明生成帘，其全局绘制顺序高于交互层、低于边框。

## 4. 表情体系

积极表情 6 种：欢喜、安心、期待、温柔、得意、放松。

轻度消极表情 4 种：犹疑、烦躁、委屈、郁闷。

- 初始生成池保持积极/消极约 3:2。
- 随着本局消除行数增长，积极与平静色系权重继续提高。
- 不使用恐惧、厌恶、尖牙、血丝、夸张哭泣等令人不适的视觉符号。
- 约 50% 的新色块携带表情；其余只保留颜色，降低满盘时的视觉噪音。
- 表情固定放在横块最左侧逻辑格；横块右侧预留给未来收藏物，数据结构使用 `collectibleType / collectibleCell`。
- 色块表情只使用直接绘制在线块上的五官，不加圆形底、不加腮红，飞行代币除外。

## 5. 局内布局

- 顶部左侧：本局分数与最高分同卡对比。
- 顶部中间：带独立浅色底卡的表情瓶与本局收集数量；与分数卡、暂停键共用同一垂直中线，标题与数字也分别对齐。
- 顶部右侧：暂停键，并为微信胶囊区保留横向余量。
- 中部：单行轮播提示；前 10 次挑战每 10 秒切换玩法提示，之后每 30 秒切换暖心句。
- 棋盘下方：下一排预览。预览块高度固定为 30 设计像素，并复用正式色块的描边、上沿高光与下沿暗面，使其一眼可识别为“将要进入棋盘的小色块”。
- 下一排预览位于独立遮挡板上，遮挡板宽度大于棋盘外框并从左右各多覆盖 19 设计像素；遮挡板与棋盘底边相接，顶层棋盘边框覆盖接缝，新行从裁剪区底边进入，棋盘外不得出现完整色块。
- 底部：并排显示解压锤、魔法棒图标入口和右上角 0/1 数量角标，不常驻展示道具名。点击后以短句加循环动画说明效果；无库存时提供带视频符号的“获取”按钮，有库存时提供“立即使用”。

## 5.1 首页布局与成长信息

- 左上角为用户档案卡：默认顺心头像与“顺心朋友”，点击头像后在微信小游戏环境内请求头像昵称授权。
- 档案卡同时展示等级、当前经验和进度条；每级经验采用 `ceil(15 × 1.32^(等级-1))`。
- 档案卡右侧展示开心瓶数量；中部演示区展示“正在收集开心瓶”水位，与局内瓶子共用竖向液面表现。
- 中部演示完整复用局内因果顺序：横移、重力下落、满行碎裂、表情贝塞尔飞入瓶子、瓶盖弹开回落。
- 表情进度跨日永久累积；目标固定为 666（`HAPPY_BOTTLE_TARGET`），满瓶得到 1 枚开心瓶。不做每日重置、周瓶日历或满瓶领道具。
- 次级入口：解忧秘境与排行榜分列演示区两侧；设置入口提供音量/震动与 GM 发放。
- 档案卡中的名称、等级徽章与经验行使用同一左侧基线；开始按钮引导手从右下斜向伸向按钮，点击触发分层水波纹。
- 玩法提示位于开始按钮上方，每 4.2 秒淡出切换，涵盖移动、消除、收集与满瓶转化。

## 6. 交互验收

1. 消除带表情的色块时，碎裂与表情飞行同时开始。
2. 表情沿二阶贝塞尔曲线进入顶部瓶子；到达后数量刷新。
3. 每次到达触发瓶盖上弹、轻微偏转、压回三段动画。
4. 当前临时用「分享给好友」获取一次使用机会（微信无成功回调，回到前台且停留 ≥3 秒判定成功）；激励视频代码与图标保留，用户量达标后改回看视频。网页预览提供模拟分享成功/过快失败。
5. 点击解压锤或魔法棒先展示动画说明弹窗；获取成功后角标从 0 刷新为 1，并立即进入目标选择，不需要再次点击道具。待使用时中央提示闪烁，所有色块轻微抖动；选中目标后反馈立即结束。解压锤仍支持从图标拖出并松到目标上使用。
6. 有“横移后经重力可满行”的机会且 8 秒无操作时，小手演示移动；任何触摸立即中断并复位。
7. 未破纪录时，“最高记录”位于右侧最高分下方；破纪录后标签缓动到左侧并变为“新纪录，继续保持”。
8. 消除碎裂完成后立即开始重力动画，不增加等待段；长距离下坠最长约 0.28 秒。
