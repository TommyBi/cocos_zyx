# 美术与 UI 设计准则

最新确认：2026-11-14。适用于后续角色、开心豆、图标、背景、按钮、面板、弹窗、奖励效果及宣传图设计。与旧美术文档冲突时，采用本准则及用户后续明确反馈。

## 核心方向

回到用户认可的初版气质：**稍偏手绘的日式动漫，柔和唯美、温暖治愈，角色自然可爱。** “精致”通过构图、线条、配色、表情和细节体现，不能靠增加立体体积和反光来体现。

- 线条自然、轻盈，可保留细微手绘起伏；颜色柔和，以清透、低对比的色块和足够留白建立层次。
- 材质偏哑光、纸感、轻柔绘画上色。允许克制的柔和阴影与色彩过渡，但不能形成雕塑感、抛光面或明显的三维倒角。
- 日式动漫感体现在情绪、构图、柔和光色与绘画笔触；保持界面可读、操作清楚。
- 场景提供温柔的氛围，角色、数值、按钮和弹窗的视觉语言统一；不要把二维手绘角色放进油亮的三维按钮体系。

## 开心豆与角色

- 以二维手绘的小伙伴为目标，轮廓亲切、表情生动、比例可爱。可延续开心豆、叶芽和开心表情等识别元素，但不能机械复制当前素材的立体质感。
- 优先用轮廓、眼神、嘴角和姿态表达可爱；小尺寸下优先保留角色识别度和表情。
- 用户本轮截图中的暖黄色开心豆被明确指出“太3D、不够可爱”，属于后续重绘需要修正的反例，不能作为新资源的正向风格参照。

## 明确避免

- 软陶、黏土、塑料玩具、半3D或3D商品渲染。
- 油亮表面、强镜面高光、大块白色反光、糖果/果冻质感、过强饱和渐变。
- 厚重立体描边、统一右下挤出厚边、鼓包式按钮、金属或抛光徽章等靠体积堆叠的 UI。
- 将“可爱”简单等同于圆润、发光、加厚或更像立体玩具。

## 提示词与验收

生成或委托新图时，正向描述需包含：二维手绘、日式动漫插画、柔和唯美、温暖治愈、自然可爱、哑光质感、轻柔阴影。排除描述需明确：3D render、clay、plastic、glossy、specular highlights、jelly/candy finish、beveled/extruded UI。不能继续沿用旧提示词中“软陶般半3D”的目标。

设计交付前，以用户认可的初版视觉作参照，比较线条、明暗、材质、可爱程度与整体氛围；在手机实际尺寸检查，不以放大后的单图精致度代替整体效果。历史原型资料可从 `docs/art-sources/archive/prototype/` 追溯，但它们不恢复旧玩法，也不意味着其中每个旧资产都已重新获准使用。

本次记录风格规则，不表示已重绘或替换当前开心豆及整套 UI；后续制作和替换资源必须遵守上述方向。

## 导航和信息层级补充 · 2026-11-14

按钮采用文字在左、图标在右；图标需要精细、流畅、风格一致，特别检查循环箭头的曲率、接点和箭头方向。暂停页重开在左、绿色继续在右，促进用户顺手继续。排行榜标题明显大于页签文字，页签高度须容纳图标和文字并留足上下内边距。首页轮播文案移至底部约20px，开始和倒计时周围留白。“开始”图片字强调自然可爱，第一版偏成熟的手写字已被用户否定，不能直接使用。

用户已允许先使用第二版圆润奶黄“开始”图片字（小芽与粉色花瓣），源图见 `ui-concepts/start-wordmark-20261114/start-cute-candidate-v2.png`。暖心救场沿用二维气球线稿，采用暖黄与奶油配色、粉色爱心贴布；消除以柔和爱心向四周扩散。危险反馈需连续的内外红色辉光，不能再用多层半透明方框叠加。

用户后续修订：暖心留言使用开心豆的大对话气泡，不使用通用标题板；文字逐字按语气快慢播放，天数粉色、加粗放大且独立留白，全部播放后才淡入并呼吸展示“收下祝福”。局内提示只渐变文字，底板固定；下一排预告始终只展示一排。

首页好友积分榜收拢在屏幕中央，两侧留出独立入口栏，左侧用于后续活动入口，不让榜单侵占。列表纵向放大，突出微信好友原始头像、昵称和分数，不能用统一小芽头像代替有效的微信头像。玩法示意略下移，视觉中心位于标题下沿与好友榜上沿之间。
