| 控制涨行 | 保留前25次单排及后期原有节奏，只在最高点不超过底部第4排时允许双排；超过第4排固定单排。消行后才满足双排时，会先生成第二排再整体上涨。 |
| 热气球救援 | 积分严格大于1000、最高点严格超过底部第6排且尚未失败时出现；沿用60秒机会间隔。约2×2格大小，从棋盘顶排区域左侧进入，10秒小幅波浪向右飞行，出口淡隐。点击暂停，拒绝或取消分享恢复剩余航程。 |
| 排行榜重复授权 | 先取回当前账号云资料，再决定是否授权；云端头像或当前账号的成功授权记录可直接复用。主动更新资料仍可重新授权；重复点击入口不会并发打开授权流程。 |

四分之一按当前棋盘的色块数量计算，向上取整，无放回随机抽取；例如13个色块抽4个，横向多格块作为一个完整色块处理。救援不引爆额外连锁，保持抽中范围；掉落产生的正常满行仍照常计分和收集。

## 热气球设计与交互

使用24帧、12fps的原生矢量序列，包含奶油金、薄荷绿、桃粉色球囊、开心豆吊篮、眨眼、火苗与随风小旗。按钮配套扭头吐舌、泪眼戳戳表情动画，没有新增位图图集或远程美术依赖。

分享成功后，每130ms投下一颗炸弹。最后一颗落地后等待500ms，所有蘑菇云与抽中块同时起爆；演出、收集和稳定结算结束后恢复游戏。弹窗、分享和演出有独立状态及输入遮罩；普通掉落不延长飞行计时，暂停菜单和分享会暂停飞行。

## 本轮 CR 已修正的问题

| 优先级 | 问题及修正 |
|---|---|
| P1 | 气球出现后玩家可能消行降高。改为记录出现、消失、兑换事件；已出现的机会可正常兑现，避免分享成功却因高度变化拿不到救援，同一机会只能兑换一次。 |
| P1 | 旧弹窗回调或取消后的迟到成功回调可能改变新状态。增加气球实例与阶段校验，分享中旧拒绝回调不解锁，取消后迟到回调不发奖励。 |
| P1 | 修改随机规则会改变服务端结算。升级棋盘V6/API9，保留V2–V5重放和V5冻结长局；服务端核验出现条件、随机结果、次数和重复兑换。结构版本仍为8，无数据重置或迁移。 |
| P2 | 将飞行时间绑到普通棋盘锁会把10秒拖长。拆出暂停菜单状态，普通掉落期间继续计时，真正暂停时姿态和剩余航程冻结。 |
| P2 | 首屏等待连消大图导致不必要阻塞。将五张大贴图移入特效分包，首屏就绪后后台加载，慢网或失败时先显示文字反馈。 |
| P2 | 冷启动云资料未返回就先授权可能重复弹窗。调整读取顺序，成功授权记录按账号隔离，并拦截并发打开。 |

未发现仍需阻断本地候选交付的未修复问题。微信真机性能、真实分享卡片和切后台行为不以浏览器结果代替。

## 包体和加载结果

以下是未压缩文件字节总和，按1MiB=1,048,576字节计算；不是ZIP大小。

| 项目 | 修改前 | 修改后 |
|---|---:|---:|
| 微信主包 | 3,491,708 B / 3.33MiB | 2,464,106 B / 2.35MiB |
| 首页分包 | 334,370 B / 0.32MiB | 334,370 B / 0.32MiB |
| 特效分包 | 无 | 1,034,459 B / 0.99MiB |
| 微信代码包总量 | 3,826,078 B | 3,832,935 B |

主包减少1,027,602字节，降幅29.4%。新增功能后总代码包只增加6,857字节；优化主要体现在减少首包与首屏等待，而不是宣称总包减少。

主包预算固定为2.75MiB，超出即构建失败；另检查特效贴图不能重复进入主包，大音乐继续保留在微信目录外的CDN产物。移动的五张贴图保留原始字节和UUID，美术质量不变；继续执行现有PNG无损压缩。本次热气球新增贴图字节为0。

慢网验收主动挂起整个特效Bundle：页面已可操作，图片特效仍未就绪，得分显示“+30”、连消显示“Good!”；放行后恢复原Sprite美术，页面异常0。该次本机冷启动到可操作约1.29秒，只代表这台机器及本地网络，不代表微信真机加载时间。
