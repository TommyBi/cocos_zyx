# 双榜与设置图标 · 本地预览

积分榜保留最高分排序；开心榜新增 `GET /v1/cocos-zyx/leaderboards?type=beans`，只读取 `players.mood_bean_balance`。累计获得量不参与排序。两榜各取前 200 名，同值并列，自己独立返回名次和值；零余额不上榜。旧 `type=power` 及其 self.bestScore 字段继续兼容；已退役的 `type=happiness` 保持拒绝，避免与过去累计榜语义混淆。

本地 UI 已实现两个页签、2/1/3 领奖台、滚动列表、底部我的排名与开心豆当前拥有量。每次打开和切换都读取服务端值；关闭或快速切换后的过期响应不会覆盖当前页。加载失败可在原弹窗内重试。旧页签内容销毁后再创建新内容，远程头像回调检查节点生命周期。

第二版按标注重新制作整体奖杯标题及金银铜领奖台。美术源文件与 ImageGen 提示词保存在 `docs/art-sources/leaderboard-v2/`；`scripts/build-leaderboard-art.py` 仅缩放、压缩并保持资源 UUID。头像、名次、数值、昵称均由实时数据叠加，图片无静态文字和假数据。前三名只展示数值及下方昵称，不再显示指标说明。开心豆与数字通过水平布局保持 6 设计像素间隔，并作为整体对齐。

面板为 640×1040，页签外框 584×64，内按钮 286×54。列表高度 409、行高 82、行间隔 10，可显示四条完整用户及半条下一用户；列表底部与固定自身卡片相隔 47，自身卡片距面板底部 24。普通行使用更明显的奶油黄底及焦糖描边，自身行使用浅绿底。移除两处榜单说明和底部关闭按钮；保留右上角关闭，点击面板空白或外部遮罩均关闭，页签、领奖台、自身卡片与滚动交互不触发关闭。

列表上方增加固定表头，底色复用当前选中页签的主题色（积分榜金黄色、开心榜浅绿色），列名为“排名、用户、积分”；切到开心榜时末列改为“开心豆”。表头在滚动区域之外，与行内排名、昵称及右侧数值对齐，使用既有字体的正常字重。按后续反馈，表头与滚动列表整体下移 10px，增加与前三名的间距；四个半条目的高度和底部自身排名卡片位置保持不变，当前列表与自身卡片间距为 37。

四张透明图共 675.96 KiB，位于现有 home 分包，通过 `prepareFeature('leaderboard')` 在打开时加载，不加入首页首屏贴图解码，也不复制进主包。

所有界面文字已切换为正常字重：中文保留原 Regular 轮廓，数字 Nunito 400；TTF 元数据为 400，位图字体 bold=0，运行时不额外加粗。原先的粗体字库生成步骤已移除。CDN 分层加载方案仍按 `docs/font-delivery-design-2026-11-13.md` 保持待评审，没有在本次功能工作中执行。

设置页继续、重新开始和退出图标使用现有 Cocos 矢量绘制入口，分别为带豆芽的圆角播放键、开心豆回转箭头、笑脸小门与出门箭头，不新增图片或字体下载。

预览地址：`http://localhost:7462/?localApi=1&home=1&preview=dual-board-v2`。

预览 Web 使用 7462，本地 API 使用 8082；数据库位于 `/private/tmp/cocos-dual-leaderboard-preview/game.sqlite`，由本地预览数据库副本初始化，并通过本地 API 创建了 9 个示例榜单账号，以检查半行和滚动效果。该预览的余额与榜单操作均在此独立副本中完成，不访问正式或测试服数据。本轮未部署双榜接口到线上。

验证产物位于 `output/dual-leaderboard-20261113/`。余额榜接口测试覆盖累计量无关、兑换后降位、无分但有豆可上榜、同余额并列、零余额不上榜、鉴权及最高分榜不变。浏览器验证覆盖真实点击双页签、快速切换、普通字重及设置图标。

本轮验证结果：客户端 171 项、服务端 48 项测试通过；TypeScript 检查及 Web/微信构建通过。320×568、390×844、768×1024 检查通过，覆盖 503 后重试恢复和延迟余额榜响应不能覆盖已切回的积分榜。微信主包 2.54 MiB，仍满足现有 2.75 MiB 项目预算。本地正常字重验证同时检查 TTF 的 400 元数据、中文字形与原 Regular 轮廓一致、两份 BMFont 的 bold=0。

第二版证据位于 `output/dual-leaderboard-20261113/v2/`。三个尺寸均验证了列表可滑动、内容点击不关闭、面板空白及外部遮罩关闭、右上角关闭、失败重试和迟到响应隔离；豆子图标与数值实际间隔 6、垂直中心一致，面板未超出屏幕。四个半条目、47 的底部间隔、24 的底部留白均有运行时几何记录。资源检查与构建通过，主包仍为 2.54 MiB，home 分包 3.65 MiB。标题按用户补充反馈重新校准到牌匾留白中心。
