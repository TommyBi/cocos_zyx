# 开心豆与体力视觉规范

> 2026-10-30 更新。旧版短圆柱拼豆及三豆簇参考图仅作历史资料，不再用于运行界面。

## 角色与资源栏

- 开心豆是柔软、略不对称的豆形小伙伴，头顶一对叶芽，带小手、小脚、笑脸和淡腮红。去掉顶部圆孔、侧壁和堆叠的手工拼豆造型。
- 单颗收集豆沿用来源心情块的主体色；被消除后统一呈现开心表情。余额与局内 HUD 使用同一个暖黄色主角，首页中央放大同一造型。
- 体力是圆润的浅绿色闪电，有微小笑脸。使用柔和绿色、奶油白高光和暖棕细线，避免高饱和玫红。
- 首页体力和开心豆都放入同宽、同高、同边框与圆形图标底座的资源胶囊。颜色分别为薄荷绿和暖奶黄；标签与数值在相同位置。
- `createMoodBean`、`createMoodBeanMascot`、`createStaminaBolt` 统一位于 `assets/script/zyxGame/MoodArt.ts`。首页顶部、首页中央、局内 HUD、结算、教程与飞行动画均调用这套程序绘制入口。

## 动画与数值

每消除一个带心情符号的色块，只生成一颗同色开心豆，沿飞行路径进入局内收集位，数字只加 1。结算额外奖励继续单列。体力开局动画使用同一枚绿色闪电，在服务端确认扣除 1 点后以 `cubicInOut` 缓动沿三次贝塞尔曲线飞向开始按钮，约 300 毫秒后进入对局。

## 小尺寸验收

顶部资源图标、局内 HUD 和结算图标分别按实际界面缩放检查。小尺寸优先保留角色轮廓、眼睛和嘴；叶芽、手脚和高光可以简化，不能重新出现旧拼豆孔或把角色缩成难辨认的三颗堆叠物。
