# 连消图片字 v1

通过内置 image_gen 生成透明 PNG；完整提示词见 prompts.json。本目录保留原始图，运行时素材在 assets/bundles/game/images/formal/。

| 等级 | 图片字 | 配色 | 倍率 |
| --- | --- | --- | --- |
| 2 连消 | Wow! | 薄荷青绿 | ×2 |
| 3 连消 | Good | 天蓝至长春花紫 | ×3 |
| 4 连消 | Great | 杏橙至暖金 | ×4 |
| 5 连消及以后 | Perfect | 粉紫渐变、金色星星和小皇冠 | ×5 |

绿色分数字图包含 0–9、+、×。运行时按 6 列 2 行、单格 128×144 拼接。最终得分和倍率分两行，避免重复乘分的歧义。

连消按连续产生满行消除的有效玩家操作累计：第一次 ×1，连续第二次 Wow! ×2，第三次 Good ×3，第四次 Great ×4，第五次及以后 Perfect ×5。某次完整操作（含自动补排）没有满行消除，则连消归零。无效拖动、普通点击和补排本身不打断连消；同次操作中的多轮掉落消除沿用该次倍率，不重复升级。基础分每排 10。

一次重力结算累计消除至少两排，稳定后奖励一枚炸弹。每段连消首次达到 Great，额外奖励一枚，可与双排奖励叠加。奖励优先附着在最底层未带炸弹的普通横块正中央；全清时在底部空格生成一块带炸弹的普通单格。附着炸弹的块可照常拖动、掉落和被消除。

点击炸弹块时，以整块几何中心为爆炸中心，移除自身及周围 3×3 范围相交的整块；偶数宽横块也对称覆盖两侧邻块。不额外连锁引爆邻近炸弹。爆破收集表情豆，爆破本身不另加分，之后掉落形成的满行照常计分。锤子或魔法棒选择状态下优先使用所选道具。

新增二十款表情沿用 MoodArt 程序线稿，不新增颜色类型，不消耗棋盘随机数。
