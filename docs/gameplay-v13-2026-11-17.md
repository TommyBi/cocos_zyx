# V13：底部特殊块与五目标放电

本地候选 `v2026.11.17.07` / 棋盘V13 / API17 / schema11。仅本地实现与预览，Staging保持API16，Production保持API13；未部署、上传微信开发版、提审或修改发布入口。V12及更早对局继续使用绑定版本重放，数据代际不变。

## 生成与随机位置

- 延续每20消行发1颗闪电、双排/三连奖励炸弹及最多3颗炸弹的规则。V13奖励在完整操作结束后预告在下一排，不把棋盘既有块突然改成特殊块。
- 在下一排8列中均匀随机选位，排除已预告的特殊块，并避免与上次奖励同列。空位可新增单格，长块则按目标列切成左段、特殊单格、右段；表情与收藏保持原对应位置且不复制。
- 炸弹与闪电都带着标记从底部升起；下排预告同时显示图标。预告满时保留待发计数，后续新排继续承接；炸弹上限包含棋盘、预告和排队奖励。

## 放电与边界

- 每颗被消除的闪电随机抽取最多5个不同的存活块，目标不足5个时全部命中。长块拆成对应宽度的单格，颜色、表情、收藏物与旧炸弹各保留唯一一份；单格直接击碎并按真实表情收集和工具分计账。
- 命中单格炸弹仍执行完整爆炸闭包，波及或直接命中其他闪电继续放电；已消失的目标不复活，不重复计奖。V12保持只击中最多3个长块的旧规则。
- 电束持续2/3秒（约0.67秒）；多层亮芯电弧、分叉、目标周围游走离子环与电芒同步播放。结束后刷新碎片、继续重力和消行，输入锁覆盖完整演出及爆炸尾部。

## 视觉与奖励按钮

- 闪电块使用哑光紫色平面块体、薄荷白分叉闪电、循环斜向扫光；与金黄体力闪电区分。主体与小电芒均留在块内，预告按实际高度自适配。炸弹标记亦按块高适配。
- 气球“帮帮我”、魔法棒视频领取、广告复活与应急清屏提示显示视频图标。视频按钮图标放在文字左侧，分享和普通导航保留现有次序。
- 使用复活卡及联网重试按钮显示已认可的复活卡原图，放在文字左侧；广告复活的文案与图标均按revive广告点位判断。

- 炸弹点击与放电起手使用effects分包 `sound_click_v1.mp3`，短促轻巧，不沿用炸弹爆破声充当放电声音；音频由本地合成，遵守现有暂停、静音、音量与前后台控制。
