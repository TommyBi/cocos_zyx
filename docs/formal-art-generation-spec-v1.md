# 《烦恼排排消》正式UI与原画生成规范 v1.0（历史方案）

> 当前正式实现已经取消“开心果”中间奖励，改为直接收集色块上的表情；请以 [`formal-ui-implementation-v2.md`](./formal-ui-implementation-v2.md) 为准。本文件仅保留早期生成规范供追溯。

> 使用对象：公司内部美术素材生成工具、美术设计师、切图与客户端接入人员。本文是当前“心情整理所”包装的正式生产基线；旧版《消除烦恼》素材清单仅作为历史尺寸参考。

## 1. 项目总述

请为竖屏微信小游戏《烦恼排排消》生成完整2D美术套装。玩家在“心情整理所”中左右移动柔软的心情块，填满整行后将杂乱心情捋顺，凝结成开心果，并在结算时装入“明日许愿瓶”。

### 核心情绪

- 温暖，但不是泛粉色女性向。
- 可爱，但不是幼儿绘本或表情包堆砌。
- 轻松，但保留清晰的棋盘策略感。
- 全年龄、性别中性、长时间观看不疲劳。
- 表达“看见、安放、整理情绪”，不表达治疗心理疾病。

### 核心视觉母题

**暖阳心情装瓶站 / Sunlit Mood Bottling Station**

世界由以下材料构成：

- 午后窗格与蜂蜜色阳光。
- 浅木整理台和磨圆边缘。
- 软蜡、纸浆、磨砂搪瓷质感的心情块。
- 半透明玻璃许愿瓶。
- 手写纸签、印章和开心果。
- 少量植物与日常小物，仅作为边缘装饰。

### 视觉记忆点

玩家应记住的不是普通“奶油色UI”，而是：

> 一排带心情印的柔软色块被压平、化成暖光，凝结一颗开心果，最后落入贴着吉签的玻璃瓶。

## 2. 设计与技术基准

| 项目 | 规范 |
|---|---|
| 引擎 | Cocos Creator 2.4.13 |
| 目标平台 | 微信小游戏，竖屏 |
| 设计分辨率 | 750 × 1334 |
| 默认适配 | Fit Height，左右保留安全裁切余量 |
| 原画源图 | 推荐1500 × 2668或更高同宽高比 |
| UI源图 | 推荐按最终显示尺寸2倍输出 |
| 位图格式 | 透明素材PNG；不透明原画PNG或高质量WebP/JPG，接入前统一转换 |
| 色彩空间 | sRGB |
| 光源 | 默认左上方，短而柔软的右下阴影 |
| 描边 | 深可可棕，不使用纯黑 |
| 文本 | 不得烘焙进按钮、标签、面板和原画 |

### 安全区

- 顶部状态区：距顶部至少80px，避开微信胶囊和异形屏区域。
- 左右主要内容安全边距：45px。
- 底部主要按钮安全边距：70px以上。
- 重要内容不得依赖最底部120px背景装饰。

### 3.1 品牌色

| 名称 | 色值 | 使用场景 |
|---|---:|---|

| 暖米纸 | `#F7E0B5` | 空格底板、次级面板 |
| 蜂蜜光 | `#F4BE4D` | 开心果、进度、奖励、满瓶光效 |
| 杏橙 | `#EF9850` | 主按钮、强调操作 |
| 珊瑚红 | `#D25E58` | 愤怒心情、少量告急强调 |
| 柠檬黄绿 | `#BECD58` | 开心心情、轻快反馈 |
| 鼠尾草绿 | `#8FB79A` | 平静心情、成功与继续 |
| 雾霾蓝 | `#7FA9C3` | 思念心情、次按钮、信息提示 |
| 深可可 | `#5A403A` | 标题、正文、描边 |
| 柔可可 | `#7C5C4C` | 次级文字、面板外框 |

### 3.2 面积比例

- 奶油、木色与浅米：55%。
- 蜂蜜黄与杏橙：18%。
- 绿与蓝：17%。
- 珊瑚红及其他强调：10%以内。
- 粉色允许作为珊瑚色邻近色，但不得成为页面主导色。

### 3.3 禁止项

- 大面积粉红、玫红、蓝紫渐变。
- 公主、婚礼、蕾丝、爱心、蝴蝶结语言。
- 霓虹、赛博朋克、暗黑魔法、写实摄影。
- 纯黑粗描边、强塑料高光、过密高频纹理。
- 背景中央出现高对比人物、文字或复杂物件。

## 4. 字体与文字层级

生成工具不得直接生成中文文本。字体由客户端统一渲染。

### 推荐角色

- 游戏标题：有手作感的圆润粗体，笔画不能过度卡通。
- 正文与按钮：清晰的现代圆体或黑体，中等字重。
- 数字与等级：圆润、开口清晰、`0/6/8`易区分的数字体。

正式选型需确认商用授权。临时版使用系统 `PingFang SC`。

- 顶部窗户不能直接位于浅色标题背后，需保留可加深区域或自然暗部。

### BG-03 玩法背景

## 6. 心情块

### 6.1 逻辑尺寸

当前棋盘为8列×10行，逻辑格尺寸76px。程序内色块显示为：

| 长度 | 最终节点尺寸 |
|---:|---:|
| 1格 | 68 × 68 |
| 2格 | 144 × 68 |
| 3格 | 220 × 68 |

建议只制作一张可九宫格横向拉伸的基础色块皮肤：

- 2倍源图：136 × 136 PNG透明。
- 最终基准：68 × 68。
- 九宫格边界：最终图左右各26px，上下各26px；中央16 × 16保持平整。
- 圆角：最终显示14～17px。
- 描边：最终显示2～3px深可可，不能纯黑。
- 高光：左上短高光；阴影：右下短阴影。

### 6.2 材质

心情块不是硬塑料糖果，应接近：

- 软蜡。
- 磨砂搪瓷。
- 轻压后的橡皮或纸浆块。
- 触感柔软，有轻微弹性但不黏腻。

不得出现：果冻透明、镜面反光、食物汁水、锋利金属边缘。

## 7. 心情印

### 7.1 设计语言

- 名称：“心情印”，不是Emoji。
- 极简圆角线稿，像陶土或纸张上的小印章。
- 统一脸型、眼距、线宽，只改变眉毛、眼睛、嘴和少量辅助符号。
- 不使用腮红、睫毛、爱心、夸张眼泪、火焰等低龄元素。
- 先做12种核心心情，通过真机验证后扩展至24或36种。

### 7.2 交付规格

- 每个图标源图：128 × 128 PNG透明。
- 单色白色图形或独立Alpha，便于程序染色。
- 图形占画布58%～68%，四周至少18px安全边距。
- 源图线宽10～12px，圆头圆角。
- 游戏中默认显示20～24px。
- 同时提供深色预览、浅色预览和16/20/24px可读性检查图。

### 7.3 首批12种

愤怒、急躁、犹疑、迷茫、难过、疲惫、思念、平静、安心、开心、期待、勇气。

### 8.1 开心果

- 文件：`happy_fruit.png`。

## 12. 月历与分享海报

### 12.1 完整月历

- 7列，最多6行。
- 空白日期为奶油白，不使用红叉或断签。
- 三档完成色依次为浅米黄、杏橙、蜂蜜金。
- 大吉大利日允许一个小开心果或星点，但不能影响日期数字。

### 12.2 月报海报

至少生成三套无文字模板：

1. **暖阳月历型**：月历占主体，适合展示整月颜色。
2. **许愿瓶型**：大瓶居中，开心果总数和称号留白。
3. **情绪色谱型**：五种主色形成柔和色带，适合个性称号。

交付两种比例：

- 750 × 1334：保存到相册、朋友圈长图。
- 1000 × 800（5:4）：微信好友转发卡片。

必须预留：游戏名、月份、开心果总数、大吉天数、称号、二维码/小游戏码安全区；文字和码均由程序渲染。

## 13. 动画与特效

### 13.1 满行“压平—化光—飞果”

总时长建议0.45～0.70秒：

1. `0～80ms`：整行心情块轻轻放大，心情印亮起。
2. `80～180ms`：色块纵向压至70%～78%，心情印短暂闭眼。
3. `160～300ms`：蜂蜜光从左向右扫过，色块化为纸屑/光点。
4. `260～420ms`：一颗开心果从行中央凝结。
5. `360～650ms`：开心果沿弧线飞入顶部收集袋。

连消时第二行起缩短20%～30%，开心果按音阶连续飞出。

### 13.2 交付形式

优先级：

1. Spine或DragonBones：适合瓶子、满瓶光效和复杂柔性动画。
2. PNG序列：适合横向光扫、开心果凝结。
3. 独立透明光效图＋程序Tween：适合按压、飞行和缩放。

特效不得大面积遮住下一步棋盘状态，亮白闪屏透明度需克制。

## 14. 音频方向

虽然本文主要服务视觉生成，正式美术动作需为音频预留节奏：

- 拖动：柔软木块/橡皮滑动声。
- 落位：短促“咔哒”，无金属感。
- 压平：轻柔纸张压合声。
- 化光：暖亮风铃或玻璃泛音。
- 开心果飞入：清脆但不尖锐的“叮”。
- 装瓶：多颗颗粒落入玻璃瓶的层叠声。
- 满瓶：2～3音的短和弦，不使用赌场式大奖音效。

## 17. 美术验收清单

### 原画

- 750×1334裁切后核心构图仍完整。
- 中央UI安全区无文字、人物、高对比物体。
- 首页与玩法属于同一房间、同一光源。
- 粉色面积未压过黄色、木色和奶油色。
- 没有水印、伪文字、乱码和生成工具标识。

### UI

- 所有按钮和标签不带烘焙文字。
- 九宫格拉伸后圆角和高光不变形。
- 默认、按下、禁用状态区别明确。
- 文字区有足够对比与留白。
- 1倍真机尺寸可读，不只在2倍预览图好看。

### 心情块与心情印

- 五种首发色在低亮度和灰度预览下仍可区分。
- 长块拉伸后无重复脸、变形脸或方向性纹理。
- 心情印在16/20/24px下轮廓仍成立。
- 图标不依赖颜色作为唯一识别信息。
- 同色系后期仍能看清相邻块边界。

### 许愿瓶

- 空瓶、半瓶、满瓶都能叠加构成。
- 缩小到首页实际尺寸仍可识别标签和瓶口。
- 玻璃边缘无绿色/粉色抠图杂边。
- 满瓶光效不遮挡标签文字。
