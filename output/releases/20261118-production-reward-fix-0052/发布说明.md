# Production 分享与广告热修复

发布 `20261118-production-reward-fix-0052`，仍为 API18/schema12/V13；只改服务端 `src/replayBoardEngine.js` 的一个判定，不需要重发前端或清缓存。

## 根因与修复

局内按钮先向后端申请奖励凭据，再调用微信分享/激励视频。清屏救场按既有玩法固定补两排，安全重放却在结束回合时误要求补满普通回合四排，随后合法操作被 `PROGRESS_INVALID` 拒绝，因此分享和视频都未执行。微信右上角普通分享不申请奖励，仍能正常打开。

修复仅让救场使用已经核对过的专用固定补排要求，普通回合仍检查最低补排；奖励凭据、完整观看观察时间、会话、种子和动作前缀等校验保留。漏补、改排数、重复补排、擅自额外补排和未结束回合仍拒绝。
