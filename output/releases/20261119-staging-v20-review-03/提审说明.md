# 微信小游戏提审候选 2026.11.19.03

已通过微信 CI 上传开发版本 `2026.11.19.03`。微信后台版本管理可选该版本提交审核。扫码预览和 ZIP 来自同一冻结目录，包固定连接 Staging API 25。审核和正式发布尚未提交。

## 问题复现与修正

微信开发者工具运行的客户端支持 V20，但启动后自动恢复了一局 V15。调试器读取的分数为 380，与截图一致。V15 当局保留三个视频锤和旧闪电规则。新版会在恢复旧局后提示从暂停菜单重新开始体验新版，新局才使用 V20。旧局保持原计分和重放规则。

## 微信开发者工具验收

- 在与上传产物一致的构建上，使用独立 Staging 账号和规则合法的 V20 棋盘。原账号的残局保留，验收后模拟器重新确认恢复原 380 分 V15 对局。
- 观察到闪电符号翻转及「点我放电」气泡。通过模拟器运行时的 Cocos 触摸输入验证闪电源被移除，生成电弧及 `lightning` 事件，分数从 1440 增至 1488。
- 通过同一输入链路打开道具弹窗，解压锤显示「分享获得（5/5）」，魔法棒显示「视频获得（5/5）」。微信真机实际分享和视频播放仍待验收。
- 256 项客户端测试、79 项后端测试、TypeScript 类型检查、分包和 GM 代码剥离检查通过。线上 Staging 沿用已验证的 V20 镜像，Production API 20 和共享网关仍沿用原容器。

## 验收与提审

使用有预览权限的微信号扫描本目录二维码。若自动恢复旧局，暂停后选「重新开始」。闪电按 V20 的进度规则累计消除 10 行后生成，通常先出现在下一排预告。首页版本号为 `v2026.11.19.03`。
